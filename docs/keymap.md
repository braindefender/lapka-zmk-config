# Lapka — Раскладка клавиатуры

36 клавиш, сплит. Подход RuEn — символы на одних местах в обоих языках.

## Переключение языка

| Действие | Способ |
|---|---|
| EN → RU | Комбо `E+R`, или `GUI+Space` на пробеле |
| RU → EN | Комбо `E+R`, или `GUI+Space` на пробеле |
| Принудительно EN | `layer_en` на NAV (левый нижний) |
| Принудительно RU | `layer_ru` на NAV (правый нижний) |

ОС: `Ctrl+0` = English, `Ctrl+1` = Русский

## Комбо

| Клавиши | Слой | Результат |
|---|---|---|
| E + R | EN | → RU |
| E + R | RU | → EN |
| X + C | EN / RU | `.` точка |
| C + V | EN / RU | `,` запятая |
| U + I | RU | Х |
| I + O | RU | Ъ |

## Слои

```
Слой 0: EN (Base)     — английские буквы
Слой 1: RU            — русские буквы (ЙЦУКЕН)
Слой 2: SYM_EN        — символы (из EN)
Слой 3: SYM_RU        — символы (из RU, через макрос &en)
Слой 4: NAV           — цифры, навигация
Слой 5: ADJ           — F-клавиши, Bluetooth, медиа
Слой 6: MOU           — кнопки мыши
```

## Layer 3: SYM_RU (Символы — Русский)

Активируется с RU слоя через `hold SYM_RU`
Клавиши с `en()` — макрос: переключает в EN, нажимает символ, возвращает в RU

```
┌───────┬───────┬───────┬───────┬───────┐   ┌───────┬───────┬───────┬───────┬───────┐
│   !   │ en(<) │   =   │ en(>) │en(`)  │   │ en(^) │ en([) │   _   │ en(]) │ en($) │
├───────┼───────┼───────┼───────┼───────┤   ├───────┼───────┼───────┼───────┼───────┤
│ \     │ (     │ -     │ )     │   +   │   │   %   │ en({) │ ;     │ en(}) │ !     │
│ GUI   │ ALT   │ CTRL  │ SHIFT │       │   │       │       │ CTRL  │       │ GUI   │
├───────┼───────┼───────┼───────┼───────┤   ├───────┼───────┼───────┼───────┼───────┤
│ en(#) │   *   │   :   │   /   │ en(&) │   │ en(@) │ en(|) │ en(~) │   ?   │   Э   │
└───────┴───────┼───────┼───────┼───────┤   ├───────┼───────┼───────┼───────┴───────┘
                │  ▽    │  ADJ  │  ▽    │   │  ▽    │ ───── │  ▽    │
                └───────┴───────┴───────┘   └───────┴───────┴───────┘
```

`!`, `=`, `_`, `(`, `)`, `-`, `+`, `*`, `%` — одинаковые в обеих раскладках, `&kp` напрямую.
`:`, `/`, `;`, `?`, `\` — используют RU-алиасы (`RU_COLON`, `RU_FSLH` и т.д.)

## Layer 4: NAV (Навигация + Цифры)

Активируется с любого базового слоя через `hold NAV`

```
┌───────┬───────┬───────┬───────┬───────┐   ┌───────┬───────┬───────┬───────┬───────┐
│   1   │   2   │   3   │   4   │   5   │   │   6   │   7   │   8   │   9   │   0   │
├───────┼───────┼───────┼───────┼───────┤   ├───────┼───────┼───────┼───────┼───────┤
│ ESC   │  ALT  │ CTRL  │ SHIFT │ ENTER │   │Win+S+S│ ←     │ ↓     │ ↑     │ →     │
│ GUI   │       │       │       │       │   │       │ SHIFT │ CTRL  │ ALT   │ GUI   │
├───────┼───────┼───────┼───────┼───────┤   ├───────┼───────┼───────┼───────┼───────┤
│ →EN   │ HOME  │  INS  │  END  │  DEL  │   │ CAPS  │ ───── │ PgDn  │ PgUp  │ →RU   │
```

Активируется через `hold ADJ` с NAV или SYM слоёв

```
│ ───── │  F9   │  F10  │  F11  │  F12  │   │  USB  │ PREV  │ PLAY  │ NEXT  │ ───── │
```

## Обозначения

| Символ | Значение |
|---|---|
| `▽` | Прозрачная клавиша (берётся с нижнего слоя) |
| `─────` | Нет действия |
| `hold` | Действие при удержании |
| `en()` | Макрос: переключает в EN, нажимает символ, возвращает в RU |
| `→EN` / `→RU` | Безусловное переключение языка (Ctrl+0 / Ctrl+1) |
